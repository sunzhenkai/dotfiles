# 审阅为低或中时继续完善，不开工

审阅已经指出判据对不住步骤、或步骤缺一块时，停下来等人在「原方案」和「按建议改」之间二选一，只是把完善做成退出。低或中因此进入完善：建议写入完成判据与步骤，同一轮再审，此阶段不改代码，也不向用户要授权。只有高且无缺陷才进入后一档开工。同一缺陷写入后再审仍在，才停在「审阅不通过」，避免把没把握的方案自己谈成高后开工。

这取代 [0025](0025-goal-reviewer-binds-on-high-confidence.md) 里「中停、低停、都不改步骤」的那一条。同一缺陷再审仍在就停的那一条，由 [0028](0028-review-loop-until-expected-or-honest-stop.md) 取代。

## Considered Options

- 维持中、低即 `已停`，等人说「仍按此方案执行」或「按审阅建议改方案」。审阅已经给出改法时，这一等不增加信息。
- 低或中直接按建议改代码。站不住的方案会在再审之前进入实现。
- 完善不设「同一缺陷再审仍在」的停点。档位可以一直停在中，goal 空转。
