# 再审只核对，派审贴上完成判据

整份重判时，句子意见和判据外的新行为会一直开出下一轮。派审若只写「范围同前」，审阅者没有可停的边界。

因此出方案时完成判据保持一条可检查的话，「不做的事」列出排除行为。每次派审原样贴上这两处和该环节的审与不审。再审只核对上一轮 P0/P1，逐条标已消失或仍在。同一条核过仍在，或第二次核对仍有 P0/P1，停在「审阅不通过」。P2 只写入坑，不挡开工。初审漏掉、且不是本次写入造成的 P0/P1，再审不补收。前提事实写错、因而走不到这条判据，仍是 P0 或 P1。

这承接 [0027](0027-low-medium-review-continues-refinement.md) 的「中或低不因此退出」和 [0029](0029-review-scope-and-completion-level.md) 的「不审设计」。[0028](0028-review-loop-until-expected-or-honest-stop.md) 里「还有下一条改法就继续」不再用于句子意见、已经核过的同一条 P0/P1，以及完成判据与「不做的事」都没有的新行为。

## Considered Options

- 只把再审改成核对，初审仍可改写完成判据。判据会在初审被加成多条产品断言，核对只是核对变大后的文本。
- 设轮次上限后开工。上限一到会把还走不到判据的方案送去实现。
- 同一条还能指出改法就继续写。完成程度会一直停在中。
