# Herdr

This configuration keeps Herdr's keybindings close to the repository's tmux
configuration:

- Prefix: `Ctrl+Space`
- Workspace navigation: `Up/Down` and `k/j` (up/down)
- Panes: `prefix+h/j/k/l`, `prefix+-`, `prefix+\\`, `prefix+z`, `prefix+x`
- Pane resize: `prefix+Shift+H/J/K/L`
- Tabs/windows: `prefix+c`, `prefix+n/p`, `prefix+1..9`
- Copy mode: `prefix+Enter`

Install and link the configuration with:

```shell
dotf herdr -ic
```
