# 交付质量闭环回归包

目标是低成本验证 skill 改动是否堵住“功能齐但 demo 化”，不把每次 patch 都变成全量产品实现。

## 分层

1. **静态门**：检查质量画像契约、三角色调用、降级确认、原文快照传递是否同时存在于 skill 与 specs。每次 patch 后必跑。
2. **窄切片**：只实现 3 个核心闭环，运行、截图、测试并按 rubric 打分。skill gate 失败时优先跑。
3. **全链路**：最后验证跨页面、跨切片一致性和数据层；不作为每轮 patch 的前置。

## 输入隔离

实现者只收样例原文与运行约束，不收质量画像、rubric 或期望页面清单。审阅者才使用质量画像与评分规则。

## 产物

所有运行证据写 `/tmp/agent-delivery-quality/`，不进共享 skill。
