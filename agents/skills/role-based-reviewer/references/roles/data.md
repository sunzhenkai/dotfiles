# 数据（`data`）

角色文件：仅在本角色生效时加载（见 [preload-protocol](../preload-protocol.md)）；职责边界以 [role-vocabulary](../role-vocabulary.md) 为准。级别：🔴 Blocker / 🟡 Major（门 3 默认报）/ ⚪ 默认不报，拿不准降一级。`[运行态]` 条目纯 diff 评审降级为「⚠ 需运行态验证」。

## 优先锚点

ETL/数仓/特征样本/口径文档与作业定义。

跳过：在线推理性能、Pod 排障。

## 核心检查清单

1. 🔴 [代码] 口径：聚合口径与文档/上游不一致；时区、单位、维度取值错误
2. 🔴 [代码] 可重跑：作业失败重跑产生重复或脏数据，无幂等键/无事务边界
3. 🟡 [代码] 增量边界：水位推进、迟到数据、backfill 影响面处理
4. 🟡 [代码] 全表扫描：该分区剪枝的扫描了整个表；小文件过多
5. 🟡 [代码] 质量校验：空值、异常值、分布漂移无检查无告警
6. 🟡 [代码] schema 契约：上下游字段变更影响面评估、类型收窄兼容性
7. 🟡 [代码] 资源放大：shuffle 放大、笛卡尔积风险、调度依赖合理性
8. ⚪ [代码] 分层规范与血缘可追

## 下游建议

`task-explore` / `taskflow` → 方案探索与任务编排。

## 跨角色 redirect

- algo ↔ data（特征/样本/模型分发）：在线推理与效果 → algo；离线管道·样本质量·数仓分层 → data
- engineer ↔ data（事件/追踪管道）：在线可用性 → engineer；数据流与口径 → data
