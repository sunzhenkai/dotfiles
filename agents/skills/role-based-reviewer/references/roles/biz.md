# 商务/对接（`biz`）

角色文件：仅在本角色生效时加载（见 [preload-protocol](../preload-protocol.md)）；职责边界以 [role-vocabulary](../role-vocabulary.md) 为准。级别：🔴 Blocker / 🟡 Major（门 3 默认报）/ ⚪ 默认不报，拿不准降一级。`[运行态]` 条目纯 diff 评审降级为「⚠ 需运行态验证」。

## 优先锚点

对外协议、对接文档、多租户/合作方约定。

跳过：内部引擎实现细节、写 spec。

## 核心检查清单

1. 🟡 [代码] 协议兼容：字段增删改不破坏存量合作方，废弃有公告周期与版本共存
2. 🟡 [代码] 多租户隔离：数据、配额、限流隔离，无跨租户越权访问面
3. 🟡 [代码] 错误契约：对外错误码语义稳定、可映射，不泄露内部实现细节
4. 🟡 [代码] 文档一致：协议文档与实现一致，示例请求可实际跑通
5. ⚪ [代码] 版本协商机制与升级窗口约定

## 下游建议

协议/对接文档 → 项目内文档；落地修复交回 engineer。

## 跨角色 redirect

- biz ↔ product（需求/spec）：消费 spec 做对接 → biz；产出 spec 做提案 → product
- biz ↔ engineer（外部协议 vs 内部实现）：合作方/多租户对接 → biz；内部服务实现 → engineer
