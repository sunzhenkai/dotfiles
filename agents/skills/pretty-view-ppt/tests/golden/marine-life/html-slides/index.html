光照、压力和食物通量随深度断崖变化

先记住三件事

  1. 分层是演化主轴，不是装饰
  2. 潮间带浅，干湿交替更残酷
  3. 生物量峰值在真光层，不在珊瑚礁明信片

海洋分区

领域 → 生境。↓ 进入各层

潮间带

高潮线 – 低潮线

  • 岩石岸：藤壶、贻贝、海星
  • 沙滩与泥滩：沙蟹、缢蛏、招潮蟹

浅海陆架

≤ 200 m

  • 海草是显花植物
  • 海獭 / 海胆 / 褐藻营养级联
  • 造礁石珊瑚与虫黄藻共生

大洋中上层

0 – 1000 m

  • 真光层：金枪鱼、鲸鲨、浮游植物
  • 中层带：灯笼鱼垂直洄游

深海与海沟

1000 – 11000 m

  • 海洋雪、鲸落、鮟鱇
  • 马里亚纳挑战者深渊：超深渊蜗牛鱼

滤食者 / 猎食者

滤食

  • 低单价、高通量
  • 鲸鲨、贻贝、藤壶

猎食

  • 高单价、低相遇率
  • 海星、鮟鱇、金枪鱼

调查清单

  1. 潮汐表、防滑鞋、铅笔
  2. 不要把海星带回家
  3. 深海：测深 → ROV → eDNA → 鉴定
