# HTML 阅读页（html-page）

本文件规定 HTML 阅读页的文件组织：何时用单页、扁平多页或层级多页，包内目录如何摆，以及 `_site.json` 如何声明页面树。视觉方向 Read `frontend-design/SKILL.md`。阅读页编辑气质与禁区按 `minimalist-ui/SKILL.md`。默认根、kind 分类与根索引服从上级 `SKILL.md`。

## 页面架构

默认单页；按内容边界、受众和维护关系升级：

| 架构 | 使用条件 | 文件形态 |
|------|----------|----------|
| 单页 | 一个主题，适合连续阅读并共同发布 | 一个 HTML |
| 扁平多页 | 多个可独立阅读的同级模块 | 一个包 + `_site.json` |
| 层级多页 | 存在稳定父子分类，分组承担总览职责 | 一个包 + `_site.json` + 分组目录 |

篇幅、标题、表格、代码或顺序关系本身都不是拆页理由。判断不确定时保持单页，不追问。

以下情况才使用多页：用户明确要求；输入本来就是多个独立文档；模块需要独立分享、评审或发布；受众或维护周期明显不同。

选择多页后再判断层级：

- 只是并列章节或附件 → 扁平多页，不制造层级。
- 能用稳定的“属于”关系描述，且每个父节点有自己的总览职责 → 层级多页。
- 只是阅读顺序、步骤先后或数量较多 → 仍是扁平结构，用排序表达，不建父子目录。
- 默认最多两级内容页；更深层级会显著增加定位与维护成本，除非用户明确要求文档站且内容确有稳定分类。

自动推断后用一句话告知：`按单页生成。` 或 `检测到独立模块，采用扁平/层级多页：<页面地图摘要>。`

## 单页

```text
YYYY-MM-DD-<slug>.html
```

路径使用 kebab-case。图片与其它资源使用同目录相对路径。

## 扁平多页

```text
YYYY-MM-DD-<slug>/
├── index.html
├── _site.json
├── topic-a.html
├── topic-b.html
└── assets/
    ├── site.css
    └── site.js          # 可选
```

`index.html` 是唯一对外入口，给出摘要、范围和完整页面地图。内容页保持同级关系，全部放在包根目录，并按 `_site.json` 提供首页、前后页或同级链接。包内共用 `assets/`，不要在每页复制一份会漂移的样式。

## 层级多页

```text
YYYY-MM-DD-<slug>/
├── index.html
├── _site.json
├── domain-a/
│   ├── index.html
│   └── topic-a.html
└── assets/
    ├── site.css
    └── site.js          # 可选
```

默认最多两级内容页；更多层级必须由稳定分类和明确导航收益证明。按真实分类建目录，每个分组目录必须有 `index.html`。分组 `index.html` 解释分组并链接直属子页；内容页通过相对路径表达“首页 → 分组 → 当前页”。

## `_site.json`：多页规范清单

多页必须创建 `_site.json`，集中声明标题、路径、顺序和层级。它是一致性检查依据，不宣称能自动生成页面。

```json
{
  "title": "展示包标题",
  "home": "index.html",
  "pages": [
    {
      "title": "领域 A",
      "path": "domain-a/index.html",
      "children": [
        {"title": "主题 A", "path": "domain-a/topic-a.html"}
      ]
    }
  ]
}
```

- `path` 是不以 `/` 开头、不含 `..` 的包内相对路径。
- `title` 与对应页面 H1 一致；扁平包不使用 `children`。
- 层级父节点指向真实分组 `index.html`。
- 页面文件不得游离于 `_site.json`；资源文件和根 `index.html` 除外。
- 所有页面使用相对 `href/src`，并能通过链接返回首页；禁止孤儿页、绝对磁盘路径和 `file:///...`。

页面变更顺序：先改 `_site.json`，再改文件、首页/分组页和页面间链接，随后检查死链、重复路径、孤儿页、H1 与顺序，最后更新根 `docs/pretty-view-html/INDEX.md`。禁止只改单页导航。
