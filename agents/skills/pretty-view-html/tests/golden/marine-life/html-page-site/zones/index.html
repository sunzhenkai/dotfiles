海洋分区

分区是稳定的「领域 → 生境」关系。本组解释四层水，并链到可单独打开的子页。

  1. 0 m 潮间带：岩石岸、沙滩与泥滩
  2. ≤ 200 m 浅海陆架：海草床、褐藻林、珊瑚礁
  3. 0–1000 m 大洋中上层：真光层与灯笼鱼
  4. > 1000 m 深海与海沟：海洋雪、马里亚纳
同一条垂直剖面里，5 米可能是褐藻森林，600 米可能是垂直洄游的灯笼鱼群。
