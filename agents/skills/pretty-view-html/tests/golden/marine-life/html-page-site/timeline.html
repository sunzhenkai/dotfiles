关键时间线

形态爆发、灭绝与人类观测是三条交错的线。每次灭绝后的恢复，才是现生类群分布的原因。

  1. 约 5.41 亿年前寒武纪生命大爆发 — 现生门类的基本身体方案出现
  2. 约 2.52 亿年前二叠纪末期灭绝 — 海洋物种损失最重的一次
  3. 6600 万年前白垩纪末期 — 海洋爬行动物退场
  4. 1977 年发现热液喷口生物群 — 生态系统可以不依赖阳光
  5. 2012 年卡梅隆下潜挑战者深渊 — 超深渊变成可重复观测
  6. 2020 年代环境 DNA 普查 — 不必捕到个体也能知道谁在水里
