调查与保护

潮间带调查和深海观测是两套清单。保护先管得着的层。

潮间带必备

  • 潮汐表和手表
  • 防滑鞋
  • 铅笔笔记本
  • 淡水冲洗瓶

不要把海星带回家；翻石头后要归位。

深海顺序

  1. 多波束测深
  2. ROV 或载人潜器走航
  3. 柱状样与 eDNA
  4. 形态 + 分子交叉鉴定

滤食者与猎食者

滤食者

  • 低单价、高通量
  • 鲸鲨、贻贝、藤壶

猎食者

  • 高单价、低相遇率
  • 海星、鮟鱇、金枪鱼
风险。 深海采矿的「试验性开采」不是可逆实验。沉积羽流会让滤食者先窒息。
