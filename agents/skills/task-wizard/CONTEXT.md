# Task Wizard

把一句任务描述拆成步骤级纲要。处在 goal 里时交给正在执行的 agent；否则交给人确认。

## Language

**任务方案**:
写给人确认的步骤级纲要。写完停下来，等人选择执行、改步骤或改路由。
_Avoid_: Goal 方案, Plan, objective

**Goal 方案**:
写给正在执行 `/goal` 的 agent 的步骤级纲要。正文自洽，含完成判据；产出之后 agent 按它继续做。
_Avoid_: 任务方案, Plan, objective, 计划

**完成判据**:
一条可检查的话，用来判断这份 Goal 方案是否做完。
_Avoid_: 目标, objective

**阻塞点**:
会卡住整份方案、需要先解开的前提。当轮解不开时成为退出点。
_Avoid_: 退出点, 坑

**退出点**:
Goal 执行必须停下来、把决定交回人的条件。方案写出来之前就能判定的也算。
_Avoid_: 暂停, 阻塞点

**授权**:
用户明确接受某条已经点名的动作或路由的那条消息。
_Avoid_: 继续, 点头

**状态**:
Goal 方案里的当前站，只取 `执行中`、`已停`、`已交接`、`已完成`。和路由一起决定下一回合做什么。
_Avoid_: 阶段, status, 任务方案

**决策点**:
会改变下一步或完成判据、且没有已查证事实的岔路。
_Avoid_: 阻塞点, 退出点, 不太确信

**审阅者**:
只属于 Goal 方案的决定角色。方案置信度为高时，它对一个决策点给出的建议就是该点的决定。
_Avoid_: 审计者, 审计, Plan Review

**建议**:
审阅者对一个决策点给出的那一个选择。方案置信度为高时，执行者照它改步骤并继续。
_Avoid_: 授权, 参考意见

**方案置信度**:
审阅者每次审阅对整份 Goal 方案打的一档把握，只取高、中、低。只有高才继续：判据可检查、步骤对着已查证事实、验证对得上判据、决策点都有建议。
_Avoid_: 复杂度, 中等, 下, 信心

**方案置信度不足**:
方案置信度为中时的退出点。完成判据写得出来，但有会改步骤的未查证假设，或验证对不住判据。
_Avoid_: 理解不够, 中等

**理解不够**:
方案置信度为低时的退出点；执行者写不出方案时也可以直接用。写不出可检查的完成判据，或步骤主体靠会改方案的猜测。
_Avoid_: 方案置信度不足

**外部参照**:
为补方案读到的一条公开做法，出处是检索、开源实现或上游文档。对上原始出处的记为事实，对不上的记为假设。
_Avoid_: 参考, 参考步骤, 建议, 参考意见

**闭门造车**:
复杂档里会改步骤的做法，定稿前没有尝试外部参照。
_Avoid_: 没调研, 调研不足
