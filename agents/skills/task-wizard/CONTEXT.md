# Task Wizard

把一句任务描述拆成步骤级纲要。处在 goal 里时交给正在执行的 agent；否则交给人确认。

## Language

**任务方案**:
写给人确认的步骤级纲要。写完停下来，等人选择执行、改步骤或改路由。
_Avoid_: Goal 方案, Plan, objective

**Goal 方案**:
写给正在执行 `/goal` 的 agent 的步骤级纲要。正文自洽，含完成判据；产出之后 agent 按它继续做。
_Avoid_: 任务方案, Plan, objective, 计划

**完成判据**:
一条可检查的话，用来判断这份 Goal 方案是否做完。
_Avoid_: 目标, objective

**阻塞点**:
会卡住整份方案、需要先解开的前提。当轮解不开时成为退出点。
_Avoid_: 退出点, 坑

**退出点**:
Goal 执行必须停下来、把决定交回人的条件。方案写出来之前就能判定的也算。
_Avoid_: 暂停, 阻塞点

**授权**:
用户明确接受某条退出点已经点名的动作的那条消息。评审收敛后的档位路由不是待授权项。
_Avoid_: 继续, 点头, 路由确认

**状态**:
Goal 方案里的当前站，只取 `执行中`、`已停`、`已交接`、`已完成`。和路由一起决定下一回合做什么。
_Avoid_: 阶段, status, 任务方案

**决策点**:
会改变下一步或完成判据、且没有已查证事实的岔路。
_Avoid_: 阻塞点, 退出点, 不太确信

**审阅范围**:
派审时交给审阅者的环节边界，并贴上当前完成判据与「不做的事」。只给范围内的意见编 P0、P1 或 P2。
_Avoid_: 决策点, 详细设计, 范围同前

**审阅者**:
只属于 Goal 方案的决定角色。每次审阅给出完成程度，以及审阅范围内的 P0、P1、P2。评审通过只看完成程度是否为高。
_Avoid_: 审计者, 审计, Plan Review

**完成程度**:
审阅者对当前审阅范围给出的把握，只取高、中、低。评审阶段是否通过只看它是否为高。有 P0 或 P1 时取中或低。Goal 方案正文里的字段名是方案置信度。定级是它的简称。不用于选择复杂度档位。
_Avoid_: 复杂度, 中等, 已达到预期

**定级**:
完成程度的简称。
_Avoid_: 复杂度, 中等, 改进意见

**改进意见**:
审阅范围内的一条改法，带 P0、P1 或 P2。写清改哪一条完成判据或步骤，并指回已有知识、已有方案或公开方案。建议是它的简称。
_Avoid_: 定级, 授权, 缺陷

**P0**:
必须解决。完成判据不可检查，或按步骤走不到判据，或漏了会改道的阻塞或退出。本轮有 P0 时完成程度取中或低。核过仍在则审阅不通过。
_Avoid_: P1, P2, 完成程度

**P1**:
必须解决。验证对不住判据。本轮有 P1 时完成程度取中或低。核过仍在则审阅不通过。
_Avoid_: P0, P2, 完成程度, 方案做不稳

**P2**:
不改道的写法、顺序、两行限制或省略。只写入坑，不参与完成程度。本轮没有 P0 与 P1 时完成程度为高并收敛。
_Avoid_: P0, P1

**评审收敛**:
完成程度为高，且没有未消失的 P0 与 P1。P2 已写入坑。此后进入「写完之后」。
_Avoid_: 已达到预期, 已完成, 范围同前

**已有知识**:
本仓已经查到的代码、文档与环境。
_Avoid_: 公开方案

**已有方案**:
当前这份方案，以及本仓里已经写过的方案。
_Avoid_: 公开方案, 改进意见

**公开方案**:
公开仓库或上游文档里的做法。复杂档定稿前的外部参照算对照过公开方案。
_Avoid_: 已有知识, 已有方案

**方案置信度**:
完成程度在 Goal 方案正文里的字段名。只取高、中、低。
_Avoid_: 复杂度, 中等, 下, 信心

**复杂度档位**:
任务走哪条衔接，只取简单、中等、复杂，对应复杂度低、中、高。简单通常是局部修改。中等通常是一个中等需求，可以跨多个模块或仓库，改动量稍大或逻辑稍微复杂。复杂是项目级重构、逻辑重塑，或业务逻辑复杂且涉及面广。命中复杂的任一条即复杂。
_Avoid_: 完成程度, 方案置信度, 定级

**完善**:
还有没核过的 P0 或 P1：写入后按审阅节核对。不是退出点。此阶段不改代码，不向用户要授权。
_Avoid_: 方案置信度不足, 已停, 放行

**诚实结论**:
一条 P0 或 P1 核过仍在，或第二次核对仍有 P0 或 P1，或写不出改法。这是退出点「审阅不通过」。只剩 P2，或还有没核过的 P0/P1，都不是这个结论。
_Avoid_: 定级, 理解不够

**理解不够**:
执行者写方案时就写不出可检查的完成判据，或步骤主体靠会改方案的猜测。评审循环开始后，改由改进意见或诚实结论处理。
_Avoid_: 方案置信度不足, 诚实结论

**外部参照**:
为补方案读到的一条公开做法，出处是检索、开源实现或上游文档。对上原始出处的记为事实，对不上的记为假设。
_Avoid_: 参考, 参考步骤, 建议, 参考意见

**闭门造车**:
复杂档里会改步骤的做法，定稿前没有尝试外部参照。
_Avoid_: 没调研, 调研不足
