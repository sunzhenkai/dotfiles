# 图解 / 对照阅读页（html-artifact）

本文件是 pretty-view **第一方蒸馏**，不是第三方 skill，**禁止**做成 `SKILL.md`。仅在门 3 已定为 HTML 阅读页、且命中本路径时 Read。

上游对照：`mesomya/html-artifact`（MIT）及其 `visual-systems.md`。本仓库不 vendor 其 `SKILL.md`。按下方规则**直写自包含 `.html`**。落盘与索引仍走门卫。

主题名（视觉系统，三选一）：默认 `technical`；备选 `editorial` / `operational`。同项目同 refer 沿用，不必每次确认；用户要换气质再确认。

HTML 在这里是**视觉思考面**，不是「把 Markdown 套一层样式」，也不是营销落地页。

## 何时用 / 何时不用

| 用 | 不用 |
|----|------|
| 对比矩阵、时间线、架构图、流程图、对照说明 | 规格/对齐/可追溯长文 → `spec-to-readable-html` |
| 要把密信息变成可扫读的空间结构（轨、带、注记、泳道） | 给人读的通用技术文档 → `html-doc` |
| 轻量可交互：tab、filter、复制、展开（控件必须真能用） | 普通长文 → `html-page` |
| | 公众号 / md→html → baoyu；翻页 → `html-ppt` |

## 工作流

1. 判定产物职责：explain / compare / plan / review / report / map / prototype / triage。
2. 读者打开后应能**理解、决定、检查或改动**什么？第一屏就要回答「这是什么」。
3. 选定**一个**视觉系统（下表），整篇贯彻，不要混搭。
4. 先选构图，再考虑卡片。把内容变成更清楚的结构，而不是原标题套 HTML。
5. 直写完整单文件（内联 CSS/JS）。决策关键内容必须保留；删套话与重复。
6. 不要发明数据、人名、工单、指标；示意数据必须标明 sample。

## 视觉系统

先定：语气、密度、底/字/1–2 个强调色、字体（展示 + 正文 + 可选等宽）、构图节奏、图形词汇。

| 名 | 何时 | 气质 |
|----|------|------|
| `technical`（默认） | 架构、对照、评审、协议 | 利落 grotesk + mono；冷灰底或深编辑底；一色强调 |
| `editorial` | 概念解释、叙事型说明 | 衬线标题 + 无衬线正文；纸色；不对称分栏、引文、边注 |
| `operational` | 流程、排障、分诊 | 紧凑无衬线 + 等宽数字；状态色当结构，不用装饰 |

## 构图（卡片要挣来）

先用这些，再放圆角框：

- 编辑跨页：大标题、deck、分栏、引文、规则线
- 左轨 / 右画布：目录或元数据轨 + 主阅读面
- 时间线 / stepper、泳道、带编号引线的注释画布
- 色带分节、矩阵表、节点-边地图、分镜
- spec sheet：标签、约束、验收

一节里超过三个同类卡片 → 改成表、时间线、轨或列表。禁止默认三等分卡片行。

## 输出规则

- 真出 HTML，不要描述「将会长什么样」。禁止 TODO、省略号、「其余同理」。
- 出现的按钮 / tab / filter / 复制必须可工作。
- 自包含：无构建、无框架、无追踪脚本。`file://` 能开。
- 动效只动 `transform` / `opacity`。
- 窄屏收成单列；宽表/代码允许横向滚动。
- 不要手写「← 目录」。

## 不要（硬失败）

- 落地页套路：顶栏登录、定价、Book a demo、假 KPI、紫蓝渐变、玻璃拟态、霓虹光斑。
- 居中 hero 开场，而不是直接进入产物职责。
- 用 Inter / Roboto / Open Sans 当「个性」。
- emoji 当结构图标；假控件；为好看丢掉关键内容。
- 源没有度量却做成仪表盘。
- 因为「要 HTML」切到 baoyu 或 `html-ppt`。
