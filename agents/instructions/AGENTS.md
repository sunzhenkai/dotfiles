## 版本与 Tag

新增版本或 Git tag 时使用 `{t|v}{a}.{b}.{c}`：

- **分支/测试**（feature、PR、预发布验证等）：以 `t` 开头，如 `t0.1.0`
- **默认分支**（main 等稳定发布线）：以 `v` 开头，如 `v1.2.3`

`a.b.c` 为语义化版本三段；tag 与对外可见的版本标识统一带前缀，避免与无前缀旧 tag 混用。
