Zones · 领域到生境

四层，不是一张明信片

潮间带 / 陆架

  • 干湿交替比深海更残酷
  • 藤壶、贻贝、海星、海獭
  • 海草是显花植物，不是海藻

中上层 / 深海

  • 真光层承担初级生产
  • 灯笼鱼垂直洄游
  • 海沟特有种：超深渊蜗牛鱼

Comparison · 能量策略

滤食者不是猎食者的反面

滤食者

  • 低单价、高通量
  • 鲸鲨、贻贝、藤壶
  • 群体可以改变局部水流
/

猎食者

  • 高单价、低相遇率
  • 海星、鮟鱇、金枪鱼
  • 感官和运动预算更贵

List · 潮间带

一次调查带什么，不带什么

  • 带上

    潮汐表、防滑鞋、铅笔笔记本、尺子、淡水冲洗瓶。

  • 不要做

    海星带回家；翻石头不归位；反复踩贻贝床。

  • 深海是另一套

    测深 → ROV → eDNA → 形态与分子交叉鉴定。
