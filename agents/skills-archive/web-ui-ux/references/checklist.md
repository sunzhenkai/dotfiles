# 完成前验收清单

BUILD / 完整流水线模式下，交付前逐项自检：

- [ ] 间距是否统一？
- [ ] 字号层级是否清晰？
- [ ] 颜色是否只用 token？
- [ ] 圆角、阴影是否一致？
- [ ] 是否有对齐问题？
- [ ] 移动端是否横向滚动？
- [ ] 长文本是否溢出？
- [ ] 内容少时是否太空？内容多时是否太挤？
- [ ] loading / empty / error / success / disabled 是否覆盖？
- [ ] 按钮点击后有没有反馈？
- [ ] 表单错误是否靠近字段？
- [ ] 网络慢时是否骨架屏？
- [ ] hover / focus / active 是否明显？
- [ ] 键盘能否操作？
- [ ] 危险操作是否有确认？是否支持撤销？
- [ ] 语义标签？aria-label？
- [ ] 对比度？
- [ ] focus-visible？
- [ ] 触控目标 44px？
- [ ] 是否用真实文案？是否考虑边界数据？
- [ ] 日期、金额、手机号格式是否统一？
- [ ] lint / typecheck / build 是否通过？
- [ ] console / network 是否干净？
- [ ] 截图是否验证 375 和 1440？
